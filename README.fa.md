# وب‌سایت شخصی و نمونه‌کار

یک وب‌سایت شخصی مدرن و واکنش‌گرا که با HTML، CSS و JavaScript خام ساخته شده است. این پروژه در ابتدا برای معرفی شخصی خودم طراحی شده، اما دیگران هم می‌توانند از آن برای ساخت و شخصی‌سازی وب‌سایت نمونه‌کار خود استفاده کنند.

**وب‌سایت را مطابق سلیقه خودتان بسازید!** رنگ‌ها، محتوا، تصویر پروفایل، لینک‌های شبکه‌های اجتماعی، رزومه و ظاهر سایت را تغییر دهید تا وب‌سایتی متناسب با شخصیت خودتان داشته باشید.

🌐 **نسخه آنلاین:** [samaneh-mirzaei.github.io](https://samaneh-mirzaei.github.io/)

## امکانات

- **تغییر پوسته تعاملی:** انتخاب از میان ۸ پوسته رنگی فعال که هرکدام پالت رنگ و هویت بصری مخصوص خود را دارند.
- **۱۰ پالت رنگی طراحی‌شده:** شامل PIM، Halloween، Oil، Twilight، Ice Cream، Late Night، Bitter Sweet، Mold، Watermelon و Night Sky. پالت‌های Oil و Late Night فعلاً فقط به‌عنوان مرجع رنگ وجود دارند و در فهرست انتخاب پوسته فعال نیستند.
- **ذخیره پوسته انتخاب‌شده:** پوسته انتخابی در `localStorage` ذخیره می‌شود و در بازدید بعدی بازیابی خواهد شد.
- **طراحی واکنش‌گرا:** سازگار با صفحه‌نمایش‌های رایانه، تبلت و موبایل.
- **معرفی شخصی:** شامل بخش ابتدایی صفحه، تصویر پروفایل، معرفی کوتاه و لینک‌های شبکه‌های اجتماعی.
- **بخش درباره من:** فضایی برای معرفی پیشینه، علایق، مهارت‌ها و اهداف.
- **دانلود رزومه:** بخشی اختصاصی برای دسترسی به فایل PDF رزومه.
- **تعاملات دسترس‌پذیر:** شامل نشانگرهای فوکوس صفحه‌کلید، لینک پرش به محتوای اصلی و پشتیبانی از تنظیمات کاهش حرکت.
- **بدون نیاز به فریم‌ورک:** ساخته‌شده با HTML، CSS و JavaScript خام.

## فناوری‌های استفاده‌شده

- HTML5
- CSS3 — شامل custom properties و چیدمان واکنش‌گرا
- Vanilla JavaScript
- Local Storage API
- آیکون‌های SVG

## شروع کار

### ۱. دریافت نسخه شخصی

مخزن را در GitHub Fork کنید یا آن را با دستور زیر Clone کنید:

```bash
git clone https://github.com/samaneh-mirzaei/samaneh-mirzaei.github.io.git
```

### ۲. باز کردن پروژه

پوشه پروژه را در ویرایشگر کد دلخواه خود، مانند VS Code، باز کنید. فایل `index.html` را با استفاده از یک سرور توسعه محلی، مانند افزونه Live Server، اجرا کنید.

### ۳. شخصی‌سازی وب‌سایت

**اطلاعات شخصی — `js/main.js`**

شیء `CONFIG` را پیدا کنید و نام و لینک‌های شبکه‌های اجتماعی را تغییر دهید:

```javascript
const CONFIG = {
  name: "Your Name",
  social: {
    github: "https://github.com/yourusername",
    linkedin: "https://www.linkedin.com/in/yourusername",
  },
};
```

نام و لینک‌های شبکه‌های اجتماعی در بخش‌های مختلف صفحه استفاده می‌شوند؛ بنابراین نیازی نیست هر لینک را جداگانه تغییر دهید.

**محتوای صفحه — `index.html`**

متن معرفی، بخش درباره من، علایق، مهارت‌ها، اهداف و توضیحات رزومه را با اطلاعات خودتان جایگزین کنید.

**تصویر پروفایل و رزومه**

فایل‌های زیر را با فایل‌های خودتان جایگزین کنید:

- `assets/profile.jpg` — تصویر پروفایل شما.
- `assets/resume.pdf` — فایل رزومه شما.

نام فایل‌ها را ثابت نگه دارید یا مسیرهای مربوطه را در `index.html` تغییر دهید.

**رنگ‌ها و ظاهر — `css/style.css`**

برای تغییر رنگ پس‌زمینه، متن، سطوح، رنگ‌های تأکیدی و سایر بخش‌ها، متغیرهای CSS مربوط به پوسته فعال PIM را ویرایش کنید. همچنین می‌توانید فونت، فاصله‌ها، حاشیه‌ها و چیدمان را شخصی‌سازی کنید.

### ۴. شخصی‌سازی پوسته‌ها

تعریف پوسته‌ها بین دو فایل `css/style.css` و `js/main.js` تقسیم شده است.

برای افزودن یا تغییر یک پوسته:

۱. متغیرهای رنگی مربوط به آن را در `css/style.css` با شناسه یکسان در `data-theme` تعریف کنید.

۲. یک مورد شامل شناسه، نام نمایشی و رنگ‌های پالت به آرایه `THEMES` در `js/main.js` اضافه کنید.

۳. شناسه هر پوسته باید در هر دو فایل یکسان باشد.

۴. کنتراست رنگ متن و پس‌زمینه را بررسی کنید و ظاهر پوسته را در بخش‌های مختلف سایت آزمایش کنید.

انتخاب‌گر پوسته، نمونه‌های رنگ را بر اساس تنظیمات پالت در JavaScript ایجاد می‌کند. انتخاب پوسته نیز به‌صورت خودکار با استفاده از `localStorage` ذخیره می‌شود.

برای غیرفعال کردن یک پوسته، مورد مربوط به آن را از آرایه `THEMES` حذف کنید. اگر می‌خواهید تعریف رنگ‌های آن را به‌عنوان مرجع نگه دارید، می‌توانید تنظیمات CSS آن را حفظ کنید.

### ۵. انتشار وب‌سایت

می‌توانید این پروژه را برای وب‌سایت شخصی خود در GitHub Pages آماده کنید.

۱. مخزنی با نام `yourusername.github.io` در حساب GitHub خود بسازید.

۲. فایل‌های شخصی‌سازی‌شده وب‌سایت را در مخزن قرار دهید.

۳. وارد بخش **Settings → Pages** شوید.

۴. شاخه انتشار و مسیر ریشه مخزن را انتخاب کنید.

۵. منتظر بمانید تا GitHub Pages وب‌سایت شما را منتشر کند.

وب‌سایت شما از طریق آدرس زیر در دسترس خواهد بود:

`https://yourusername.github.io`
