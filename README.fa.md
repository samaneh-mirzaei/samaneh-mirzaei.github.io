# وب‌سایت شخصی و نمونه‌کارها

یک وب‌سایت شخصی مدرن، واکنش‌گرا و دوزبانه (انگلیسی / فارسی) که با HTML، CSS و جاوااسکریپت خالص ساخته شده است. این پروژه در ابتدا برای صفحهٔ معرفی شخصی خودم ایجاد شد، اما هر کسی می‌تواند از آن برای ساخت و شخصی‌سازی وب‌سایت شخصی خودش استفاده کند.

**این وب‌سایت را مطابق سلیقهٔ خودتان بسازید!**

رنگ‌ها، محتوا، تصویر پروفایل، لینک‌های شبکه‌های اجتماعی، رزومه، پروژه‌ها و استایل‌ها را تغییر دهید تا وب‌سایتی داشته باشید که شخصیت و هویت شما را منعکس کند.

🌐 **نسخهٔ آنلاین:** [samaneh-mirzaei.github.io](https://samaneh-mirzaei.github.io)

## امکانات

- **تغییر تعاملی تم:** انتخاب از میان ۸ تم رنگی فعال که هرکدام پالت رنگی و هویت بصری مخصوص خود را دارند.
- **۱۰ پالت رنگی منتخب:** شامل PIM، Halloween، Oil، Twilight، Ice Cream، Late Night، Bitter Sweet، Mold، Watermelon و Night Sky. پالت‌های Oil و Late Night در حال حاضر به‌عنوان مرجع موجود هستند، اما در فهرست انتخاب تم فعال نیستند.
- **تغییر زبان انگلیسی / فارسی:** با یک کلیک، زبان تمام متن‌ها، نام تم‌ها و برچسب‌های دسترس‌پذیری تغییر می‌کند و چیدمان صفحه برای زبان فارسی به حالت راست‌به‌چپ (RTL) درمی‌آید.
- **ذخیرهٔ تنظیمات کاربر:** تم و زبان انتخاب‌شده در `localStorage` ذخیره می‌شوند و در بازدید بعدی، پیش از اولین نمایش صفحه، بازیابی می‌شوند.
- **طراحی واکنش‌گرا:** سازگار با نمایشگرهای دسکتاپ، تبلت و موبایل.
- **بخش معرفی شخصی:** شامل تصویر پروفایل، معرفی کوتاه و لینک‌های شبکه‌های اجتماعی.
- **بخش دربارهٔ من:** فضایی برای معرفی پیشینه، علایق، مهارت‌ها و اهداف.
- **صفحهٔ جزئیات:** صفحه‌ای جداگانه برای نمایش پروژه‌ها و گواهی‌نامه‌ها، همراه با امکان افزودن مطالعهٔ موردی (Case Study). اطلاعات تکمیل‌نشده تا زمان ویرایش، با جای‌نگهدارهای خط‌چین نمایش داده می‌شوند.
- **دانلود رزومه:** بخشی اختصاصی برای دسترسی به فایل PDF رزومه.
- **تعاملات دسترس‌پذیر:** شامل نشانگر فوکوس صفحه‌کلید، لینک پرش به محتوای اصلی و پشتیبانی از تنظیم کاهش حرکت انیمیشن‌ها.
- **ساختار کامپوننت‌محور:** سربرگ، پابرگ، کارت‌ها، برچسب‌ها و بخش‌های صفحه به‌صورت کامپوننت‌های کوچک و قابل استفادهٔ مجدد در جاوااسکریپت پیاده‌سازی شده‌اند و محتوا در فایل‌های داده نگهداری می‌شود.
- **بدون فریم‌ورک و نیاز به فرایند Build:** ساخته‌شده با HTML، CSS و جاوااسکریپت خالص، با استفاده از ماژول‌های ES.

## شروع کار

### ۱. دریافت نسخهٔ شخصی

مخزن را در گیت‌هاب Fork کنید یا آن را با دستور زیر Clone کنید:

```bash
git clone https://github.com/samaneh-mirzaei/samaneh-mirzaei.github.io.git
```

### ۲. اجرای پروژه

پوشهٔ پروژه را در ویرایشگر کد دلخواه خود، مانند VS Code، باز کنید و آن را با یک سرور محلی اجرا کنید.

از آنجا که جاوااسکریپت پروژه از ES Modules استفاده می‌کند، مرورگرها هنگام باز کردن مستقیم فایل‌ها از طریق آدرس `file://` ممکن است از اجرای آن‌ها جلوگیری کنند. بنابراین، باز کردن مستقیم `index.html` با دوبار کلیک ممکن است صفحه‌ای خالی نمایش دهد.

می‌توانید از هرکدام از روش‌های زیر استفاده کنید:

```bash
npx serve .                 # Node.js
python3 -m http.server      # Python
```

همچنین می‌توانید از افزونهٔ **Live Server** در VS Code استفاده کنید.

### ۳. شخصی‌سازی وب‌سایت

#### اطلاعات شخصی — `js/config.js`

نام خود را به زبان انگلیسی و فارسی و لینک شبکه‌های اجتماعی‌تان را تغییر دهید:

```javascript
export const CONFIG = {
  name: "Your Name",
  nameFa: "نام شما",
  social: {
    github: "https://github.com/yourusername",
    linkedin: "https://www.linkedin.com/in/yourusername",
  },
};
```

نام و آدرس شبکه‌های اجتماعی در هر دو صفحه استفاده می‌شوند؛ بنابراین لازم نیست لینک‌ها را در چندین فایل جداگانه تغییر دهید.

اگر به نسخهٔ فارسی نیاز ندارید، می‌توانید تنظیم `nameFa`، فایل `js/i18n/fa.js` و قابلیت تغییر زبان را نادیده بگیرید.

#### متن‌های صفحات — `js/i18n/en.js` و `js/i18n/fa.js`

تمام متن‌های وب‌سایت در این دو فایل قرار دارند و از کلیدهای یکسان استفاده می‌کنند.

متن معرفی، بخش دربارهٔ من، علایق، اهداف، متن‌های مربوط به رزومه و توضیحات پروژه‌ها را در فایل `en.js` با محتوای دلخواه خود جایگزین کنید.

سپس ترجمهٔ همان کلیدها را در فایل `fa.js` قرار دهید. اگر کلیدی در `fa.js` وجود نداشته باشد، متن انگلیسی آن به‌عنوان مقدار جایگزین نمایش داده می‌شود.

#### مهارت‌ها، پروژه‌ها و گواهی‌نامه‌ها — `js/data/`

| فایل | کاربرد |
|---|---|
| `skills.js` | برچسب‌های مهارت در بخش دربارهٔ من |
| `projects.js` | کارت‌های پروژه شامل تصویر، برچسب‌ها، نقش و لینک‌ها |
| `certificates.js` | کارت‌های گواهی‌نامه شامل تصویر، صادرکننده، تاریخ و لینک تأیید |
| `caseStudies.js` | مطالعه‌های موردی اختیاری؛ فعال‌سازی از طریق `FEATURES.caseStudies` در `js/config.js` |
| `navigation.js` | لینک‌های سربرگ هر صفحه |
| `themes.js` | گزینه‌های موجود در انتخاب‌گر تم |

برای افزودن یک پروژه، ابتدا یک مورد جدید به `projects.js` اضافه کنید و سپس متن‌های `d.pN.title` و `d.pN.desc` مربوط به آن را در فایل‌های `en.js` و `fa.js` تعریف کنید.

اگر می‌خواهید بخش نقش و لینک‌ها به‌صورت جای‌نگهدار نمایش داده شوند، مقدار `role` و `links` را `null` قرار دهید. در غیر این صورت، مقادیر واقعی را وارد کنید تا جای‌نگهدارها با اطلاعات شما جایگزین شوند.

#### تصویر پروفایل، رزومه و تصاویر

فایل‌های زیر را با فایل‌های شخصی خود جایگزین کنید:

- `assets/profile.jpg` — تصویر پروفایل شما.
- `assets/resume.pdf` — فایل رزومهٔ شما.
- `assets/projects/` و `assets/certificates/` — تصاویر بندانگشتی پروژه‌ها و گواهی‌نامه‌ها که در صفحهٔ جزئیات نمایش داده می‌شوند.

نام فایل‌ها را ثابت نگه دارید یا مسیرهای متناظر را در فایل `js/sections/Hero.js`، فایل `js/sections/Resume.js` و فایل‌های موجود در `js/data/` به‌روزرسانی کنید.

#### رنگ‌ها و استایل‌ها — `css/`

برای تغییر رنگ پس‌زمینه، متن، سطوح، رنگ‌های تأکیدی و سایر بخش‌های وب‌سایت، متغیرهای سفارشی CSS مربوط به تم فعال PIM را در فایل `css/base/themes.css` ویرایش کنید.

تنظیمات تایپوگرافی، شعاع گوشه‌ها و حداکثر عرض در فایل `css/base/tokens.css` قرار دارند. هر کامپوننت نیز فایل استایل اختصاصی خود را در پوشهٔ `css/components/` دارد.

### ۴. شخصی‌سازی تم‌ها

تعریف تم‌ها بین دو فایل `css/base/themes.css` و `js/data/themes.js` تقسیم شده است.

برای افزودن یا ویرایش یک تم:

1. متغیرهای معنایی رنگ آن را در `css/base/themes.css` تعریف کنید و از شناسه‌ای یکسان با ویژگی `data-theme` استفاده کنید.
2. یک مورد به آرایهٔ `THEMES` در فایل `js/data/themes.js` اضافه کنید. این مورد باید شامل شناسه، نام انگلیسی، نام فارسی (`nameFa`) و رنگ‌های پالت باشد.
3. شناسهٔ تم در هر دو فایل باید دقیقاً یکسان باشد.
4. کنتراست متن را بررسی کنید و ظاهر تم را در بخش‌های مختلف وب‌سایت آزمایش کنید.

انتخاب‌گر تم، نمونه‌های رنگی را از تنظیمات پالت در جاوااسکریپت تولید می‌کند. انتخاب کاربر نیز به‌صورت خودکار در `localStorage` ذخیره می‌شود.

برای غیرفعال کردن یک تم، مقدار `enabled: false` را در ورودی مربوط به آن در `js/data/themes.js` قرار دهید.

اگر می‌خواهید تعریف رنگ آن تم را به‌عنوان مرجع نگه دارید، لازم نیست تنظیمات CSS آن را حذف کنید. در حال حاضر، تم‌های Oil و Late Night به همین روش از فهرست انتخاب پنهان شده‌اند.

### ۵. انتشار وب‌سایت شخصی

می‌توانید این پروژه را برای انتشار وب‌سایت شخصی خود در GitHub Pages آماده کنید.

1. در حساب گیت‌هاب خود مخزنی با نام `yourusername.github.io` ایجاد کنید.
2. فایل‌های شخصی‌سازی‌شدهٔ وب‌سایت را در آن قرار دهید.
3. وارد بخش **Settings → Pages** شوید.
4. شاخهٔ انتشار و پوشهٔ اصلی مخزن را انتخاب کنید.
5. منتظر بمانید تا GitHub Pages وب‌سایت شما را منتشر کند.

وب‌سایت شما از طریق آدرس زیر در دسترس خواهد بود:

`https://yourusername.github.io`

```text
├── css/

│   ├── rtl.css             # تنظیمات تایپوگرافی و چیدمان فارسی

├── js/
│   ├── main.js             # نقطهٔ ورود: رندر صفحه و راه‌اندازی قابلیت‌ها
│   ├── theme-init.js       # اعمال تم و زبان ذخیره‌شده پیش از نمایش اولیه
│   ├── config.js           # نام، لینک‌های اجتماعی و تنظیمات قابلیت‌ها
│   ├── data/               # داده‌های پروژه‌ها، گواهی‌نامه‌ها، مهارت‌ها و تم‌ها
│   ├── i18n/               # فایل‌های en.js، fa.js و ابزارهای ترجمه
│   ├── components/         # اجزای قابل استفادهٔ مجدد: سربرگ، پابرگ، کارت‌ها و برچسب‌ها
│   ├── sections/           # بخش‌های صفحه: معرفی، دربارهٔ من، پروژه‌ها و غیره
│   ├── pages/              # تعیین بخش‌های تشکیل‌دهندهٔ هر صفحه
│   ├── features/           # قابلیت‌ها: تم، زبان و نمایش تدریجی هنگام اسکرول
│   └── utils/              # ابزارهای پاک‌سازی HTML و مدیریت امن localStorage
└── assets/
    ├── profile.jpg
    ├── resume.pdf
    ├── fonts/              # فونت وزیرمتن برای زبان فارسی
    ├── projects/
    └── certificates/
```

## نحوهٔ عملکرد پروژه

هر صفحهٔ HTML تنها یک ساختار اولیه دارد؛ شامل `body` با ویژگی `data-page="home"` و یک عنصر خالی با شناسهٔ `app`.

فایل `js/main.js` صفحهٔ موردنظر را شناسایی می‌کند، بخش‌های آن را با استفاده از کامپوننت‌ها درون `#app` ایجاد می‌کند و سپس قابلیت‌های تغییر تم، تغییر زبان و نمایش تدریجی هنگام اسکرول را راه‌اندازی می‌کند.

کامپوننت‌ها توابع ساده‌ای هستند که رشته‌های HTML برمی‌گردانند. هر عنصر قابل ترجمه نیز با ویژگی `data-i18n` مشخص می‌شود تا هنگام تغییر زبان، متن آن بین فایل‌های `en.js` و `fa.js` جابه‌جا شود.

از آنجا که محتوای صفحه با جاوااسکریپت تولید می‌شود، در صورت غیرفعال بودن جاوااسکریپت، بدنهٔ صفحه برای بازدیدکنندگان و خزنده‌های وب خالی خواهد بود. با این حال، عنوان و توضیحات صفحه در HTML باقی می‌مانند.
